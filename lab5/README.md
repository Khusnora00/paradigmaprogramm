Лабораторная работа №5

Тема

Объектно-ориентированное программирование в Python.

Цель работы

Изучить принципы объектно-ориентированного программирования, создание классов и объектов, инкапсуляцию данных, проверку входных данных и обработку исключений.

Описание проекта

В проекте реализованы следующие классы:

1. Student

Представляет студента и хранит информацию о нём:

* ID студента;
* имя;
* учебную группу;
* оценки;
* средний балл;
* статус допуска.

Класс проверяет корректность идентификатора, имени, группы и оценок.

2. GradeBook

Предназначен для управления списком студентов:

* регистрация студентов;
* поиск по ID;
* проверка уникальности идентификаторов;
* формирование рейтинга по среднему баллу.

3. Payment

Представляет финансовую операцию. Проверяет тип операции и корректность суммы платежа.

4. StudentAccount

Представляет счёт студента и поддерживает:

* начисление денежных средств;
* оплату;
* проверку достаточности средств.

Индивидуальный вариант №14

Тема: Оплата обучения 

В индивидуальном варианте реализованы два класса: Payment и StudentAccount.

Класс Payment отвечает за финансовые операции:

* начисление денежных средств;
* оплату;
* проверку типа операции;
* проверку корректности суммы;
* запрет нулевых и отрицательных сумм.

Класс StudentAccount представляет счёт студента и позволяет:

* создавать счёт с именем студента;
* начислять денежные средства с помощью метода charge();
* списывать денежные средства с помощью метода pay();
* хранить и обновлять текущий баланс;
* проверять достаточность средств перед оплатой.

Для проверки работы классов используются автоматические тесты, которые проверяют создание платежа, начисление денежных средств и оплату.

Структура проекта

* lab5.py — реализация классов.
* test_lab5.py — автоматические тесты.
* README.md — описание проекта и инструкция по запуску.

Запуск тестов

Откройте терминал в папке проекта и выполните команду:

py -m unittest test_lab5.py -v

Если все тесты пройдены успешно, в конце появится сообщение OK.

Результат

В ходе лабораторной работы реализованы классы для управления данными студентов и финансовыми операциями. Выполнена проверка входных данных, предусмотрена обработка исключений и проведено автоматическое тестирование основных функций.
