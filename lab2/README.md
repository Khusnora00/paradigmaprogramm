Лабораторная работа № 2

Тема: Парадигмы программирования

Цель работы

Изучить основы императивного программирования, научиться работать с переменными, изменением состояния, условными конструкциями и циклами в Python.

Задания

Задание 1. Исследование изменения состояния

Исследование изменения значения переменной при выполнении последовательных операций присваивания. Заполнение таблицы изменения состояния и проверка результата программы.

Задание 2. Расчёт стоимости покупки

Ввод цены товара, количества товаров и процента скидки. Вычисление стоимости покупки без скидки, размера скидки и итоговой стоимости.

Задание 3. Управление выполнением с помощью условия

Определение оценки по введённому баллу с использованием конструкций if, elif, else. Проверка корректности введённых данных.

Задание 4. Накопление состояния в цикле

Вычисление суммы всех чисел и суммы положительных чисел, а также подсчёт положительных, отрицательных чисел и нулей с использованием цикла без функции sum().

Задание 5. Поиск максимального значения

Поиск максимального элемента списка без использования функции max(). Изменение переменной maximum при обнаружении большего значения.

Задание 6. Обязательное сравнительное задание

Сравнение императивного и декларативного стилей программирования на примере вычисления суммы положительных чисел списка.

Индивидуалный вариант № 19

Тема: Обработка оценок

Подсчёт количества оценок A, B, C и F в списке из 10 оценок с использованием цикла for, условных конструкций и счётчиков.

Диапазоны оценок:

* A: 90–100 баллов;
* B: 75–89 баллов;
* C: 50–74 балла;
* F: 0–49 баллов.

Используемые средства

* Язык программирования Python.
* Среда разработки Visual Studio Code.

Результат работы

В ходе лабораторной работы были изучены изменение состояния переменных, условные конструкции, циклы, накопление значений и поиск максимального элемента. Также были рассмотрены различия между императивным и декларативным стилями программирования.
