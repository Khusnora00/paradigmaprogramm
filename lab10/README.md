6. Объяснение цепочки логического вывода

Рассмотрим дисциплину artificial_intelligence.

Для её изучения необходимо освоить:

* data_structures;
* databases.

Для изучения data_structures необходимо освоить programming_2.

Для изучения programming_2 необходимо освоить programming_1.

Таким образом, получается следующая цепочка:

artificial_intelligence
        |
        |---- data_structures
        |          |
        |          |---- programming_2
        |                     |
        |                     |---- programming_1
        |
        |---- databases

Prolog проверяет всю цепочку зависимостей, включая косвенные пререквизиты.

7. Ответы на контрольные вопросы

1. Чем факт отличается от правила и запроса в Prolog?

Факт — это утверждение, которое считается истинным в базе знаний.

Правило — это логическое условие, определяющее связь между объектами.

Запрос — это вопрос к базе знаний, на который Prolog ищет ответ.

2. Как унификация связывает переменные и почему pair(X, X) не унифицируется с pair(aida, miras)?

Унификация — это процесс сопоставления двух термов и связывания переменных.

В выражении pair(X, X) обе позиции должны содержать одно и то же значение. Поэтому pair(aida, miras) не подходит, так как aida и miras — разные атомы.

3. Что такое точка выбора и как пользователь запрашивает следующее решение?

Точка выбора — это возможность Prolog вернуться к предыдущему этапу поиска и попробовать другой вариант решения.

Для получения следующего ответа пользователь нажимает точку с запятой (;).

4. Зачем рекурсивному правилу базовый случай и как возникает бесконечный поиск?

Базовый случай необходим для завершения рекурсии.

Если рекурсивное правило постоянно вызывает само себя и не достигает базового случая, поиск может стать бесконечным.

5. Чем проверка всех транзитивных пререквизитов отличается от проверки непосредственных?

Проверка непосредственных пререквизитов учитывает только прямые зависимости дисциплины.

Транзитивная проверка дополнительно учитывает все косвенные зависимости, поэтому она позволяет точнее определить готовность студента к изучению курса.

8. Анализ унификации, возврата и зацикливания

Унификация: позволяет сопоставлять структуры и связывать переменные с конкретными значениями.

Возврат: Prolog использует механизм backtracking для поиска всех возможных решений. Следующие результаты можно получить нажатием клавиши ;.

Зацикливание: при наличии циклических зависимостей рекурсивный поиск может не завершиться. Для предотвращения этой проблемы реализован предикат safe_prerequisite/2, который использует список посещённых курсов и проверяет, не встречался ли курс ранее.
