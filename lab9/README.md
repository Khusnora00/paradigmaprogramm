Выполненные задания

Задание 1. Сравнение двух стилей

Получение имён студентов с оценкой не ниже 75.
Использование цикла for.
Использование спискового включения.
Сравнение результатов оператором ==.

Задание 2. Условия для коллекции

Использование функций any() и all().
Вычисление среднего балла.
Проверка изменения посещаемости.

Задание 3. Регулярные выражения

Проверка кодов групп.
Проверка адресов электронной почты.
Исправление неправильного email.

Задание 4. Создание базы SQLite

Создание таблицы students.
Добавление данных студентов.
Использование параметризованных SQL-запросов.

Задание 5. SQL-запросы

Выборка и сортировка данных.
Группировка студентов.
Использование COUNT(), AVG(), WHERE и HAVING.

Задание 6. Интегрированный результат

Получение рейтинга студентов из SQLite.
Проверка email с помощью регулярных выражений.
Вывод итогового рейтинга.

Посещаемость не ниже 85%.
Оценка не ниже 60.
Проверка наличия оценки не ниже 90 с помощью any().
