2. Цель проекта 

Цель проекта — разработать систему регистрации студентов на учебные дисциплины с проверкой пререквизитов, расписания занятий и ограничения по количеству кредитов.

Программа позволяет загружать каталог дисциплин, находить нужные курсы, формировать учебный план и проверять возможность регистрации студента.

Проект демонстрирует применение различных парадигм программирования, модульной организации кода, объектно-ориентированного подхода и автоматического тестирования.

3. Основные возможности

Система поддерживает следующие функции:

* Загрузка каталога учебных дисциплин из JSON-файла.
* Хранение информации о дисциплинах.
* Поиск дисциплины по идентификатору.
* Регистрация студента на дисциплину.
* Проверка повторной регистрации.
* Проверка выполнения необходимых пререквизитов.
* Проверка конфликтов расписания.
* Контроль максимального количества кредитов.
* Расчёт общего количества кредитов.
* Формирование информации об учебном плане.
* Вывод результатов регистрации.
* Автоматическое тестирование основных функций.

Каталог содержит 20 учебных дисциплин.

Описание файлов и модулей

main.py

Главный файл программы. Отвечает за запуск приложения и взаимодействие с пользователем через консольное меню.

paradigm_comparison.py

Дополнительный файл для сравнения процедурного и объектно-ориентированного программирования на примере регистрации студента на дисциплину.

Содержит основную логику работы системы: загрузку каталога, поиск дисциплин, регистрацию, расчёт кредитов и формирование учебного плана.

Файл с данными о 20 учебных дисциплинах.

tests/test_registration.py

Модуль автоматических тестов для проверки правильности работы системы.

requirements.txt

Файл для перечисления внешних библиотек, необходимых проекту. Если используются только стандартные библиотеки Python, дополнительных зависимостей может не потребоваться.

5. Инструкция по запуску

5.1. Требования

Для запуска проекта необходимы:

* Python 3;
* Windows или другая операционная система с поддержкой Python;
* терминал Windows или терминал VS Code.

5.2. Открытие проекта

Откройте папку проекта Сро 1 в VS Code.

Откройте терминал и убедитесь, что текущая директория соответствует папке проекта.

Выполните команду:

После запуска должно появиться консольное меню системы регистрации студентов.

Далее пользователь может выбирать доступные операции и следовать инструкциям программы.

5.4. Запуск сравнения парадигм

Для демонстрации двух подходов выполните:

py paradigm_comparison.py

Программа демонстрирует регистрацию студента с использованием процедурной функции и объекта класса Student.

Для проверки количества дисциплин в каталоге выполните:

Для запуска тестов выполните:

Тесты проверяют основные сценарии регистрации, включая успешные и неуспешные операции, ограничения по кредитам, пререквизиты и конфликты расписания.

6. Использованные парадигмы программирования

6.1. Императивное программирование

В проекте используются переменные, присваивания, условия и последовательное выполнение команд. Эти конструкции позволяют управлять процессом регистрации и проверять выполнение необходимых условий.

6.2. Процедурное программирование

Процедурный подход применяется для разделения задач на отдельные функции. Например, функции поиска дисциплины и расчёта кредитов позволяют выполнять конкретные операции независимо друг от друга.

В файле paradigm_comparison.py процедурный подход представлен функцией procedural_registration().

6.3. Структурное и модульное программирование

Программа разделена на отдельные модули, каждый из которых выполняет определённую задачу.

Модели отвечают за представление данных, сервисы — за основную логику, файл данных — за хранение каталога, а тесты — за проверку правильности работы программы.

Такое разделение упрощает сопровождение проекта и поиск ошибок.

6.4. Объектно-ориентированное программирование

В проекте используются классы для представления дисциплин и учебного плана.

Объекты объединяют данные и связанные с ними операции. В дополнительном файле paradigm_comparison.py класс Student демонстрирует хранение имени студента и списка зарегистрированных дисциплин.

6.5. Абстракция и композиция правил

В модуле services/rules.py используется общий абстрактный класс EligibilityRule и отдельные классы правил проверки.

Класс CompositeRule объединяет несколько правил. Это позволяет проверять регистрацию по нескольким условиям и упрощает добавление новых проверок.

6.6. Функциональный подход

Функции используются для выполнения отдельных операций над данными, например расчёта общего количества кредитов.

Чистые функции, неизменяемость данных и другие принципы функционального программирования могут дополнительно применяться для повышения предсказуемости и надёжности системы.

Функции высшего порядка, рекурсия и ленивые вычисления могут быть использованы при дальнейшем расширении проекта.

9. Сравнение процедурного и объектно-ориентированного подходов

Для сравнения используется одна задача: регистрация студента на учебную дисциплину.

Процедурный подход

Функция procedural_registration() получает имя студента, название дисциплины и список зарегистрированных дисциплин. Затем выполняет необходимые проверки и добавляет дисциплину в список.

Преимущество этого подхода заключается в простоте реализации отдельных операций.

Объектно-ориентированный подход

Класс Student хранит имя студента и список зарегистрированных дисциплин. Метод register_course() выполняет регистрацию, используя данные объекта.

Преимущество этого подхода заключается в объединении данных и методов внутри одного объекта.

Результат сравнения

Оба варианта решают одну задачу. Процедурный подход удобен для небольших операций, а объектно-ориентированный подход помогает организовывать данные и поведение в рамках классов.
