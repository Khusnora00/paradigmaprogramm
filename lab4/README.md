# Лабораторная работа №4
## Разработка системы рейтинга студентов университета

### 1. Титульная информация

*Дисциплина:* Программирование  
*Тема:* Разработка системы рейтинга студентов университета  
*Студентка:* Корганбаева Хуснора  
*Группа:* ТИИ 25-21  
*Индивидуальный вариант:* №2 — фильтрация допущенных студентов

### 2. Цель и постановка задачи

*Цель работы:* изучить принципы модульной организации Python-проектов, разделения ответственности между модулями, проверки данных и автоматического тестирования.

*Задачи:*
- Разработать пакет university_rating.
- Реализовать проверку данных студентов и их оценок.
- Рассчитать средний балл каждого студента.
- Определить статус допуска на основе среднего балла.
- Отсортировать студентов по среднему баллу в порядке убывания.
- Обработать случаи отсутствия оценок.
- Реализовать индивидуальное расширение — фильтрацию допущенных студентов.
- Создать автоматические тесты для проверки корректности программы.

4. Исходный код

Исходный код всех модулей представлен в файлах пакета university_rating, а автоматические тесты находятся в каталоге tests.

Основные реализованные функции:

* validate_scores() — проверяет оценки.
* validate_student() — проверяет запись студента.
* calculate_average() — рассчитывает средний балл.
* determine_status() — определяет статус допуска.
* build_student_result() — формирует результат для одного студента.
* build_rating() — создаёт отсортированный рейтинг.
* filter_admitted() — возвращает только допущенных студентов.
* format_rating() — формирует текстовый отчёт.

Индивидуальный вариант №2 предусматривает фильтрацию только допущенных студентов.

Для реализации расширения используется функция filter_admitted(students). Она формирует рейтинг и возвращает только записи со статусом «допущен».
