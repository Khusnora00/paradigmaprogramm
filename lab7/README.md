## 2. Постановка задачи

Разработать модуль анализа студенческого рейтинга,
который проверяет корректность баллов, выполняет
нормализацию оценок, вычисляет средний балл,
определяет статус студента и формирует рейтинг.

Дополнительно необходимо реализовать рекурсивный
поиск позиции элемента и подготовить автоматические
тесты для проверки основных функций программы.
