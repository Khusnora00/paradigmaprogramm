# Лабораторная работа №3
## Процедурное программирование

### Цель работы
Изучить принципы процедурного программирования, разделение программы на функции и модульное тестирование.

### Задание 1. Экзаменационная ведомость
Программа обрабатывает оценки студентов и формирует рейтинг.

Реализованы функции:
- validate_score() — проверка корректности балла.
- validate_student() — проверка данных студента.
- calculate_average() — вычисление среднего балла.
- determine_status() — определение допуска.
- summarize_student() — создание сводной информации.
- build_rating() — формирование рейтинга.
- filter_students() — фильтрация студентов.
- format_report() — формирование текстового отчёта.

##Индивидуальное задание: Расчёт стипендии
Программа проверяет данные претендента и рассчитывает размер выплаты.

Реализованы функции:
- validate_applicant() — проверка данных претендента.
- base_amount() — определение базовой суммы.
- calculate_bonus() — расчёт дополнительной выплаты.
- format_decision() — формирование итогового решения.
